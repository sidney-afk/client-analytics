## Client behavior and rollback

Clients continue using the deployed site because the draft is unmerged and the
tools, roles and schema are unapplied to production. Anonymous writer
authentication and all application/runtime bytes remain unchanged.

Before installation, withdrawing this source changes no saved work. After any
future approved recovery, retain the source package and restored evidence.
Only an observed rollback to a verified empty target permits retry in place.
A committed or uncertain target is preserved for review; use a fresh target for
another attempt. Deleting a package is never a database rollback.

Any missing callable, unsupported target, unexplained schema/row/sequence
difference, ambiguous result or missing restore evidence holds progression.
Installation, live capture, cloud recovery and activation require separate
owner-authorized execution gates. Product watchers remain inactive and Decision A
is not claimed by this draft.
