Unread badges

One rule everywhere: a filled badge means something new for you, and its colour and icon say what it is. Orange pencil is a change request, blue bubble is a comment, grey person is a staff message, violet eye is Kasper. An outlined orange badge means change requests you have already read that are still open. Automatic records never get a badge.

1. The kinds

The same badges appear on calendar cards, Samples cards, the Messages list and the Messages button.

3. Hover (or long-press on a phone): what it is before you open it

Up to three newest unread items, newest first: kind, who, which part, the first line and when. Clicking an item opens Notes at that message. Opening the preview does not mark anything read; opening Notes does.

4. The Messages button

The count sits on the corner, so the icon never moves (left: today, the icon slides 9 px left, 11 px with two digits). It counts conversations with something new for you and takes the colour of the most important kind waiting: change, then comment, then staff. It is live from page load. Hover says what is waiting.
