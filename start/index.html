How to sort the footage

Five rules. Point at one to see it in the folders.

  1. One folder per script.
  2. Three folders inside it: Main Camera, Side Camera, Audio.
  3. One clip per folder.
  4. No side camera or audio? Skip that folder.
  5. Keep the folder names exactly like this.
